SURVIVAL ISLAND
================

A 2D Pixel-Art Survival Island game.

GAME FEATURES
-------------
- Pixel-Art island
- Player movement
- Day and night system
- Wood, stone and berries
- Axe and pickaxe crafting
- Raft crafting
- Food system
- Save and load system
- Mobile joystick controls
- Pixel-style UI
- PWA support
- Offline support through Service Worker

CONTROLS
--------
Joystick : Move the player

USE      : Collect resources / use nearby objects
CRAFT    : Craft tools and raft
EAT      : Eat berries to restore food
SAVE     : Save game progress

HOW TO PLAY
-----------
1. Explore the island.
2. Collect wood, stone and berries.
3. Craft an axe and pickaxe.
4. Collect enough resources.
5. Craft the raft.
6. Reach the raft to escape the island.
